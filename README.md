# 7枚形ティア表

エンスクドリルの7枚形カードを使ってティア表を作る授業用ツールです。

## 使い方

- カードをドラッグして `S神 / A強い / B普通 / C弱い` に配置できます。
- カードの名前と受け入れ枚数は黒いマスクで伏せられ、クリックで表示/非表示を切り替えられます。
- 右下の `↻` ボタンでカードを裏返し、積み木表示を確認できます。
- 裏面下部のマスをクリックすると待ち牌候補を赤くマーキングできます。
- 生成練習では、カード18種の型を元に、同数シフト・左右反転・萬筒索ランダムで出題できます。

## GitHub Pages

静的サイトなので、リポジトリ直下を GitHub Pages で公開できます。

1. GitHubで新規リポジトリを作成します。
2. このフォルダの内容をリポジトリへpushします。
3. GitHubの `Settings > Pages` で `Deploy from a branch` を選びます。
4. Branch は `main`、folder は `/ (root)` を選びます。
